# 0.96-inch TFT LCD display (ST7735S) release notes

This library provides functions to support a 0.96-inch TFT LCD driven by an ST7735S controller. This is the display used on the SHIELD_XENSIV_A shield.


## What's included?

- APIs for initializing/de-initializing the driver
- APIs for writing the display data

See the [README.md](./README.md) and the [API reference guide](https://infineon.github.io/display-tft-st7735s/html/index.html) for a complete description of the display-tft-st7735s.
