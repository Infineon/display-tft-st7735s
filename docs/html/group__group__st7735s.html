ST7735S TFT Display Driver

General Description

Driver for the ST7735S 0.96-inch 80 x 160 resolution RGB TFT panel over a 4-wire SPI interface.

The driver owns the full panel bring-up (reset, power/gamma/frame configuration, color format, orientation) and provides windowed pixel writes. It is instance based: one mtb_st7735s_t object per physical panel.

As the caller owns the SPI block, initialize and enable it before calling mtb_st7735s_init. Pixel data is streamed as-is; the caller is responsible for supplying the panel's byte order (big-endian RGB565).

The driver sends plain 8-bit byte buffers, so the SPI block must be configured to match the ST7735S:

  • SPI master, 8-bit data width (RX and TX)
  • MSB first
  • SPI mode 0 (CPOL = 0, CPHA = 0)
  • SCLK up to 15 MHz

Snippet 1: Initializing the ST7735S controller

The following snippet demonstrates how to initialize the ST7735S display over a 4-wire SPI interface with the D/C and Reset GPIO configuration.

cy_rslt_t result;
cy_en_scb_spi_status_t initStatus;
/* Initialize SPI for interfacing with display. */
initStatus = Cy_SCB_SPI_Init(CYBSP_SPI_CONTROLLER_HW,
&CYBSP_SPI_CONTROLLER_config,
&spi_context);
if (CY_SCB_SPI_SUCCESS != initStatus)
{
CY_ASSERT(0);
}
Cy_SCB_SPI_Enable(CYBSP_SPI_CONTROLLER_HW);
/* Map the display pins to the baseboard and configure the orientation. */
const mtb_st7735s_config_t config =
{
.pins =
{
.dc_port = DISPLAY_DC_PORT,
.dc_pin = DISPLAY_DC_PIN,
.rst_port = DISPLAY_RST_PORT,
.rst_pin = DISPLAY_RST_PIN,
},
.orientation = MTB_ST7735S_ORIENTATION_LANDSCAPE,
};
/* Initializes the display. */
result = mtb_st7735s_init(&display, CYBSP_SPI_CONTROLLER_HW, &config);
if (CY_RSLT_SUCCESS != result)
{
CY_ASSERT(0);
}

Snippet 2: Filling the screen

The following snippet shows how to set the address window and stream pixel data to fill the whole panel with a solid color.

/* Fill the whole screen with Ocean-500. */
uint8_t row[MTB_ST7735S_PANEL_HEIGHT * 2U];
for (uint32_t x = 0U; x < display.width; x++)
{
row[2U * x] = (uint8_t)(OCEAN_500_RGB565 >> 8);
row[2U * x + 1U] = (uint8_t)(OCEAN_500_RGB565 & 0xFFU);
}
mtb_st7735s_set_address_window(&display, 0U, 0U,
display.width - 1U,
display.height - 1U);
for (uint32_t y = 0U; y < display.height; y++)
{
mtb_st7735s_write_data_stream(&display, row,
(uint32_t)display.width * 2U);
}

Function Documentation

◆ mtb_st7735s_init()

cy_rslt_t mtb_st7735s_init ( mtb_st7735s_t *  obj,
CySCB_Type *  spi_inst,
const mtb_st7735s_config_t *  config 
)

Initializes an ST7735S panel: Configures the D/C and Reset GPIOs, performs a hardware reset, runs the full panel configuration sequence, applies the requested orientation, turns the display on, and selects the full-screen address window.

The SPI block referenced by spi_inst must already be initialized and enabled by the caller.

Precondition
obj, spi_inst and config must be non-NULL.
config->pins.dc_port and config->pins.rst_port must be non-NULL.
config->orientation must be a valid mtb_st7735s_orientation_t value.
Parameters
[out]objDriver instance.
[in]spi_instSPI SCB base used to interface with the ST7735S.
[in]configPin and orientation configuration (copied internally).
Returns
Always returns CY_RSLT_SUCCESS; the return value is reserved for future use.

Sets the column (CASET) and row (RASET) address window that the subsequent pixel stream is written into, applying the panel start offsets, and issues RAMWR so the panel is ready to receive pixels.

Coordinates are inclusive and in display (post-orientation) pixels.

obj must be non-NULL and initialized by mtb_st7735s_init.

[in]y2End row.

Releases the D/C and Reset GPIOs (set to analog Hi-Z).

The SPI block is owned by the caller and is left untouched. No other API is valid on obj after this call.
